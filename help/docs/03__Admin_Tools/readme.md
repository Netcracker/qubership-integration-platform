# Admin Tools

> ⛔️ This functionality is not available via the VS Code Extension.

## Description

---
This tab is intended to provide the functionality for Administrators.

## User Interface

---

### View "Admin Tools" Section
Click "Admin Tools" main tab on top of the screen to get access to additional sections:

- [Domains](1__Domains/readme.md) - shows details about domains and engines.
- [Variables](2__Variables/readme.md) - allows to manage common and secured variables.
- [Audit](3__Audit/readme.md) - contains tracking information about performed operations in the system.
- [Import Instructions](4__Import_Instructions/readme.md) - allows to manage import instructions.
- [Design Templates](7__Design_Templates/readme.md) - allows to manage templates, utilized for chain document generation.
- [Sessions](5__Sessions/readme.md) - contains details about all registered sessions in the system.
- [Access Control](6__Access_Control/readme.md) - allows to globally manage roles for HTTP Triggers.
- [Testing](9__Testing/readme.md) - contains test cases, endpoint mocks and test runs across all chains.

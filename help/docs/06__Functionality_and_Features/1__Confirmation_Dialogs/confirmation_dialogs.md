# Confirmation Dialogs

## Description

### Overview

To mitigate the risk of accidental data corruption or loss, there are dialog windows introduced across the application. Such dialog windows will require from the user additional confirmation of action (usually it is data removal, update or leaving the unsaved changes). The format of the message is presented below:

# Metrics & Session Monitoring

## Description

---

### Overview

In order to maintain system monitoring, quickly react to the processing deviations according to the established support processes,Cloud Integration platform provides the list of important metrics, that were carefully aligned with the best practices, discussed and approved by architectural team.
